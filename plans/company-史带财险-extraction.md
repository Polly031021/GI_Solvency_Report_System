## 3. 版式差异与处理

1. 全文检索"实际资本表""S02""最低资本表""S05"均 0 命中：这两张明细表在正文里没有章节小标题，只能靠表头列（项目/本季度/上季度/下季度预测数）与行项（核心一级资本、巨灾风险/市场风险/信用风险）识别，故 ACTUAL_CAPITAL、MINIMUM_CAPITAL 不写 anchor_terms，靠页码窗口 + required_items 判定。
2. MINIMUM_CAPITAL 在 2023-2025 年为跨页三块（巨灾风险 / 市场风险 / 信用风险），每块表头重复，通用规则按"第 N 页表格分块"切块属正常跨页，不是版式损坏；max_pages=3 容纳。
3. LIQUIDITY_MONITORING 分两块（回溯不利偏差率 + 十项监测指标），第二块表头为"监测指标/本季度末累计"，故 start_item/end_item 置空，整页线框取全表。
4. 史带无车险业务，经营表"车险签单保费""车险车均保费"四年均为"-"；标准化按未发生处理（不写 0）。
5. 金额单位：四份报告表体均为"元"（不是万元），比值行为百分号字符串，由标准化层换算为万元/比率。

## 4. 未映射说明

未映射指标集中在"S05-最低资本表"分块：巨灾、市场、信用三张子表的行次在每块内从 1 重新编号，且行项是资本拆分明细（利差风险、交易对手违约风险、风险分散效应等），指标字典只收录合计项与主要分项，因此出现 6-14 个未映射行。处理原则：保留原文、不写 0、不做跨块合并，避免把"风险分散效应"（减项）误当资本占用。
