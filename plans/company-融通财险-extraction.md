## 3. 版式差异

1. 全册小册子季报模板（S01/S02/S05 编号 + 2.x 章节），表名与东吴、比亚迪同源。
2. **SOLVENCY_MAIN 文本层列间距消失**：标签与首个金额粘连、上季度数并入同格，如
   `1认可资产 | 4 | 73,408.74538,167.77 | 454,336.24`。按行内勾稽可还原（见 §5）。
3. 表头无“元/万元”字样 → 单位未识别（该表实为万元，与 S02/S05 的元口径差 10⁴）。
4. ACTUAL_CAPITAL 续页列结构偏移（31 页起多出“3.2/3.3”序号列），通用按分块拼接可接受。
5. 经营表 17/18 页各一分块，18 页续块首行被插入 `【第18页表格分块】` 标记行（已在 YAML 用
   `start_item: [保险业务收入]` / `end_item: [其他渠道签单保费]` 约束）。
6. 流动性表首块表头缺失（首行空白标签的 LCR3/未来三个月…），第二块才有表头；
   两块的“经营活动净现金流”口径不同：回溯表为季度、监测表为累计，通用规则按表内位置取用。

## 4. 未映射/缺陷说明

- 7 条 `RAW_*` 全部可解释：
  - `（二）百元保费经营活动净现金流`、`（三）特定业务现金流支出占比`、
    `（七）AA 级（含）以下境内固定收益类资产占比`、`（八）持股比例大于 5% 的上市股票投资占比`、
    `（九）应收款项占比`、`（十）持有关联方资产占比`：流动性监测指标在指标字典中无编码
    （沿用其他小型公司现状，字典扩容后自动映射）。
  - `递延所得税资产（由经营性亏损引起的递延所得税资产除外）`（S02 附属一级资本行）：
    字典有 `DEFERRED_TAX_ASSET_*`，但该行在续页、标签被换行拆成“递延所得税资产（由经营性亏 损…”，
    未命中精确匹配；同表“对净资产的调整额/各项非认可资产”已正常映射，属标签断行问题，不影响合计行。
- **未修复缺陷（需专属 extractor 才能修，本次按“只改 YAML”约束保留）**：
  SOLVENCY_MAIN 的标签-金额粘连使标准化结果为
  认可资产 0.0004、认可负债 0.0001、最低资本 0.0003、核心/综合充足率 10.00%，
  且 `unit: 万元` 声明未生效（表仍按默认“元”÷10⁴，下季度预测列 454,336.24 → 45.43）。
  同一现象在比亚迪保险 2025 已有记录（其 YAML 亦未修）。
- 共享层问题（文件:行号 + 复现）：`services/batch_processor.py:238-246` 的
  `unit = detect_table_unit(grid)` 只看表内文字，配置里 `tables.X.unit` 不参与覆盖；
  复现：本单 `SOLVENCY_MAIN` 表头无单位、格子数值被切碎 → 单位未识别 → 回退默认“元”换算，
  而 YAML 已写 `unit: 万元` 仍被忽略（第二次复跑结果不变）。

## 5. 关键指标核对（2025Q4，万元）

| 指标 | 本季度末 | 上季度末 | 下季度末预测 | PDF 原文（元） |
|---|---|---|---|---|
| 认可资产 | 473,408.74 | 538,167.77 | 454,336.24 | 文本层切碎，见下 |
| 认可负债 | 165,797.63 | 231,124.03 | 144,091.99 | 同上 |
| 实际资本 | 307,611.11 | 307,043.73 | 310,244.25 | 3,076,111,143.83（S02 合计） |
| 最低资本 | 30,222.05 | 48,289.47 | 29,118.12 | S05 量化 296,163,922.50；控制/附加仅主表可读 |
| 核心偿付能力充足率 | 1010.42% | 629.87% | 1057.77% | — |
| 综合偿付能力充足率 | 1017.84% | 635.84% | 1065.47% | — |

**勾稽自证（认可资产/认可负债 的还原口径）**

- 473,408.74 − 165,797.63 = 307,611.11 = 实际资本合计 ✓（S02：3,076,111,143.83 元 = 307,611.11 万元）
- 量化风险 29,616.39 + 控制风险 605.66 + 附加 0 = 30,222.05 = 最低资本 ✓（S05：296,163,922.50 元）
- 307,611.11 ÷ 30,222.05 = 1017.84% = 综合充足率 ✓；305,369.31 ÷ 30,222.05 = 1010.42% = 核心 ✓
  （核心一级资本 305,369.31 万 = 3,053,693,128.65 元，S02 首行）
- 认可资产 473,408.74 万 = 47.34 亿，与经营表总资产 48.26 亿（认可率 ~98%）自洽。

经营表：保险业务收入本季度 27,600.64 / 累计 138,646.80；净利润 1,501.64 / 6,767.05；
总资产 482,593.77；净资产 316,796.14；签单保费累计 7,144.29；综合费用率 21.33%、综合赔付率 84.85%；
近三年平均投资收益率 3.00%、综合 3.06%（均与 PDF 一致，单位元→万元换算正确）。
