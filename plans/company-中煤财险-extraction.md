# 中煤财险 2022–2025 提取规则

## 1. 结论

- 规则文件：`config/extraction/companies/中煤财险.yaml`（canonical `中煤财险`，aliases `中煤财产` / `中煤财产保险股份有限公司`），**未新增 extractor**，通用层即可定位 5 张目标表。
- 2022：5 表 / 160 行 / 113 条标准化记录 / 57 个编码；2023：6 表 / 161 行 / 201 条记录 / 98 个编码，两年定位与抽取均成功。
- **2024、2025 无法提取**：两份 PDF 均为纯扫描件（第 4 节），0 表 0 行，属数据源缺陷而非规则缺陷。

## 3. 版式差异与规则要点

1. 2023 年起各表整体后移一页（2022 版式 → 2023 版式），故 `structure_versions` 以 `since: 2023` 分档；`since: 2024` 条目仅用于标注数据源缺陷。
2. 实际资本表、最低资本表两年均为两页、续页无表头（2022 第 25 页、2023 第 27 页），窗口给 `[n, n+1]`，由通用层整页线框识别合并；2023 第 34 页为 3 张表，通用层已整页保留。
3. 2022 年无“近三年平均投资收益率”表（全册无“近三年”字样），属原文披露缺失，不造数。
4. 偿付能力主表用章节锚点“偿付能力指标”定位，避免命中第 3 页目录；概览表单位为万元，实际资本表/最低资本表表内为“单位：元”，已由单位字段换算。
5. 经营指标表 2022/2023 同构：保险业务收入、净利润、总资产、净资产、保险合同负债、ROE、ROA、投资收益率，终止项取“综合成本率”。

## 4. 数据源缺陷：2024/2025 为纯扫描件

- `Data/pdfs(2024)/中煤财险.pdf`：33 页；逐页 `get_text()` 仅第 1 页 76 字符（封面），其余全部 0 字符，每页 1 张整页图片。
- `Data/pdfs(2025)/中煤财险.pdf`：35 页；同样仅封面 79 字符，每页 1 张图片。
- 环境内无 tesseract / pytesseract / easyocr / paddleocr / rapidocr；`pymupdf.Page.get_textpage_ocr` 接口存在但无引擎可用。
- 因此 **2024 年认可资产/实际资本/最低资本无法给出**，需对该 PDF 做 OCR 或替换为可检索版本后重跑。
