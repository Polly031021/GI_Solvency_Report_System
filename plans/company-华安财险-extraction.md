# 华安财险（华安财产保险股份有限公司）跨年度提取规则

范围：`Data/pdfs(2022)/华安财险.pdf`、`Data/pdfs(2023)/华安财险.pdf`、
`Data/pdfs(2024)/华安财险.pdf`、`Data/pdfs(2025)/华安财险.pdf`，共 4 份四季度报告
（2022 = 41 页，2023 = 40 页，2024 = 40 页，2025 = 38 页“报告摘要”版）。
页码均为 PDF 物理页（1 起）。实测环境：Windows + 仓库 `.venv`，未改共享代码、未做 git 写操作。

## 0. 结论

- 公司级 YAML：`config/extraction/companies/华安财险.yaml`（`rule_version: 1`、`extractor: huaan`、
  六表全部 `tolerance: 0` 精确窗口 + `page_match: prefer`，不按年维护 `structure_versions`）。
  封面公司四年均为“华安财产保险股份有限公司”，别名命中 `华安财产保险股份有限公司` / `华安财产保险`。
- 公司 extractor：`services/company_extractors/huaan.py`（`@register("huaan")`），只用 PDF 文本重建
  三张被通用逻辑带偏的表——最低资本表、流动性风险监测指标表、近三年（综合）投资收益率表；
  只改 `rows` / `table_blocks` / `source_pages` / `unit` / `strategy`，不写死年份页码，幂等。
- 主要经营指标表不用 extractor：YAML 用 `start_item: [保险业务收入]` / `end_item: [其他渠道签单保费]`
  替换掉通用的“综合成本率”终止项后，从 13 行（表头 + 12 行）恢复为完整的 32 行（表头 + 31 行）。
- 回归（官方命令，`--no-excel`）：2022 5/6 表、2023/2024/2025 6/6 表，四年状态均“成功”；
  2022 的缺口是“近三年（综合）投资收益率”表——全册 41 页无“近三年”字样，属披露缺失，不是漏检。
- 标准化：2022 = 169 条 / 80 编码 / 9 未映射；2023 = 175 / 82 / 9；2024 = 175 / 82 / 9；
  2025 = 175 / 82 / 9。2022 少 2 个编码：实际资本表“其他附属一级资本”为“-”（按缺失处理、
  不生成记录，2024 该行有 7,756.78），最低资本表没有“1* 量化风险最低资本（未考虑特征系数）”行。
- 关键指标（认可资产、认可负债、实际资本、最低资本、保险业务收入、净利润、综合成本率、签单保费、
  综合偿付能力充足率、近三年平均投资收益率）四年逐项与 PDF 一致，见第 4 节。

版式要点：

- 六表都排在“四、主要指标”与“十、实际资本 / 十一、最低资本”两个区块，年内位置固定；
  2025 起改为摘要版，四表整体前移约 5 页，表头与行标签完全不变，因此不需要 `structure_versions`。
- 偿付能力主表 = p20/20/21/16 上半“（一）偿付能力充足率指标”（15 行，表头 序号|项目|本季度数|
  上季度可比数|下季度预测数）；流动性两张指标表紧随其后，2024 起监管指标与监测指标合并成一张
  “类别|序号|项目|本季度数|上季度数”表（类别列竖排成“流动性风/险监管指/标”碎行，脚注编号
  “1”“2”单独成行，末行“其他流动性指标 / 20 / 无 / -- / --”）。
- 主要经营指标 = p21/21/22/17 下半“（四）主要经营指标”（31 行），2023 起同页下半还有
  “（五）/（四）近三年（综合）投资收益率”（两行标签 + 两个百分数，标签与数值分行）。
- 实际资本表（S02）= 行次|项目|期末数|期初数，30 个数据行；最低资本表（S05）= 行次|期末数|期初数
  （**没有“项目”列**，PDF 文本层逐单元格一行，个别标签折行）；2023 起多一行“1* 量化风险最低资本
  （未考虑特征系数）”，2022 没有。
- 2022 第 33 页“八、管理层分析与讨论”里有一张“（2）与上季度末预测对比”小表，含
  “最低资本（万元） 289,983.19 / 289,922.33 / 0.02”——这正是 MINIMUM_CAPITAL 定位到 p33 的原因；
  2023/2024/2025 则被偿付能力主表（p20/p21/p16，含“最低资本”行）抢走。

## 2. YAML 设计要点

- `tolerance: 0` + 四年实测页全部列入 `expected_pages`：窗口就是这几页，避免 p20 主表与 p21 经营表
  互相“借页”（tolerance 2 时窗口会横跨相邻表）。`page_match: prefer` 仍保留窗口未命中时回退全文
  锚点的兜底，2022 的近三年表靠它得到空定位（缺失），而不会被等宽窗口错命中。
- 经营表：`start_item: [保险业务收入]` / `end_item: [其他渠道签单保费]`。通用配置以
  “综合成本率/综合赔付率”为终止项，会把第 12 行之后的分组标题、签单保费、前五大险种、分渠道
  明细整段裁掉；换成经营表首末行后四年都是 32 行。
- 近三年表：`anchor_terms` / `required_items` 用表内两行标签“近三年平均投资收益率”
  “近三年平均综合投资收益率”（标题“近三年（综合）投资收益率”在文本层是整行，作为辅助）。
- 最低资本表：`anchor_terms` 保留“最低资本表 / （一）最低资本表”作为标题证据，但**对定位页码无效**
  ——文本层一行一个单元格，`line_has_item(require_value=True)` 取不到“标签+同行数值”，start 命中
  为 0；真正决定页码的是定位器的内置边界变体（见第 5 节缺陷 1），由 extractor 纠正。
- `company.notes` 记录“2025 摘要版页码前移”“2022 无近三年表属披露缺失”，供后续维护者参考。

## 3. extractor 设计（services/company_extractors/huaan.py）

`postprocess(tables, *, pdf_bytes)` 用前 2 个参数，按表 id 分派，缺表时 `FlexibleTable` 补建
（`source_pages`、`table_blocks` 与 `rows` 同步，保证 STEP3 按 block 展开时拿到同一份数据）。

1. **MINIMUM_CAPITAL**：全文按页找“行次 + 期末数 + 偿付能力最低资本”同页的最低资本表页；
   逐行解析 行次（`^\d+(?:\.\d+)*(?:\*)?$`，兼容 1*）→ 标签（连续非数值行拼成一行，修
   “境外固定收益类资产价格风险”+“最低资本”折行）→ 两个数值（`-` 保留为值，不吞行）；
   输出 `指标名称|期末数|期初数`，止于“（二）非寿险业务保费风险最低资本和准备金风险最低资本”
   或“十二、”。2022 无表对象时补建；`table.page` / `source_pages` 改回真实页 40/39/39/37。
   不能把“巨灾风险最低资本”“非寿险业务保费风险”当停止词——它们是表内行标签。
2. **LIQUIDITY_MONITORING**：从“（三）流动性风险监测指标”或“（二）流动性风险监管指标和流动性
   风险监测指标”起，下一页开头 10 行内出现监测标签则并入。只保留 10 个监测指标，先去掉行首序号
   （`^\d{1,2}(?![\d.%])`），再取标签后的数值；若首个数值是单个数字（脚注“2”）则丢弃；监管部门
   “经营活动净现金流回溯不利偏差率RDR（%）”因标签后缀不匹配被排除。表头在小节窗口内取
   （2022/2023 `项目|本季度数|上季度可比数`，2024 `项目|本季度数|上季度数`，2025
   `指标名称|本季度数|上季度数`），按页拆 block。
3. **THREE_YEAR_INVESTMENT_RETURN**：两个标签都出现才重建；取第一个标签之后的两个百分数按顺序
   分配（华安是“标签1 / 标签2 / 值1 / 值2”四行，不能照抄太保“每个标签各取下一个数值”），
   输出 `指标名称|本年累计` + 两行，`unit="%"`。2022 不补建。

不碰 SOLVENCY_MAIN、经营表、实际资本表：前者表头/列数与数值都正确，后两者的行由 YAML 与通用逻辑
已经完整（经营表 32 行、实际资本表 31 行）。

## 5. 共享层缺陷（未修改，仅记录）

1. **最低资本表定位错页**：`services/solvency_pdf_locator.py:553` 定义、:930 调用的 `_expand_to_item_boundaries`
   在页码窗口选页后用 `boundary_variants("MINIMUM_CAPITAL")` 重扫**全文档**（`occurrences()` 不限于
   selected 页），“最低资本”同时命中首/尾，把 2022 p33 管理层小表闭合成 1 页；2023/2024/2025 命中
   偿付能力主表。`range_has_formal_section_heading` 的正式章节正则
   `^(?:第)?(?:[一二三四五六七八九十百]+|\d+)(?:[、.．]|[）)])...最低资本(?:表|明细表)?$`
   不认“（一）最低资本表”（全角括号开头），S05 页因此拿不到 formal_section_heading 加分。
   `_RULE_TO_CONFIG_FIELDS` / `_DIRECT_FIELDS` 都没有 `boundary_variants`，YAML 的
   `start_item` / `end_item` 在此表上被完全覆盖，无法用配置修正。
   复现：`PYTHONIOENCODING=utf-8 ./.venv/Scripts/python.exe tmp/huaan_debug_locate.py`
   （输出 2022 MINIMUM_CAPITAL pages=[33]，2023 [20]，2024 [21]，2025 [16]）。
2. **一份公司 YAML 校验失败会拖垮所有公司**：`services/extraction_rules.py:292` 的
   `load_company_rules()` 遇到任一非法配置直接上抛（例如 aliases 含 canonical，:223 抛
   `ExtractionConfigError`），上层退化成“未命中公司规则”，`tmp/tools/dump_tables.py` 对**所有**公司
   输出 0 表、四行占位。本次首版 alias 误含“华安财险”时即全库失效，去掉后恢复（20 条规则）。
   建议：逐文件容错并记录坏配置，而不是让单文件错误升级为全局失效。
3. **资本明细的“-”被当成 0**：`services/solvency_normalizer.py:97` `CAPITAL_COMPONENT_ZERO_CODES`
   配合 :1368-1386，对 ACTUAL_CAPITAL / SOLVENCY_MAIN 中 核心/附属一二级资本 的空白与“-”写成 0
   （代码注释称“资本明细短横线保留 0 规则”）。华安 PDF 用“-”表示无余额，标准化后
   CORE_T2_CAPITAL / ANC_T2_CAPITAL = 0，与验收要求的“0 与 `-` 区分”相冲突；太保 2024 同样 0/0，
   属共享层既定行为。若需保留缺失语义，应改为生成“值为空”诊断而不是 0。

## 6. 遗留与诊断

- 未映射 9 项（2024 实测，`standard_data` 里 `RAW_*` 编码）：流动性监测表的“百元保费经营活动
  净现金流”“特定业务现金流支出占比”“AA级（含）以下境内固定收益类资产占比”“持股比例大于5%的
  上市股票投资占比”“应收款项占比”，S05 的“偿付能力最低资本”“非寿险保险风险最低资本合计”，
  S02 的“递延所得税资产（由经营性亏损引起的递延所得税资产 除外）”（核心一级扣减与附属一级加回
  两处同名反向）。这些标签在 `services/solvency_metric_registry.py` 没有对应编码，属词典缺口，
  不是提取错误；经营表分组行“（十一）效益类指标/（十二）规模类指标”与附加资本子行按分组标题
  过滤，不计入未映射。
- S02 实际资本表里“递延所得税资产（由经营性亏损引起的…除外）”在核心一级资本扣减与附属一级
  资本加回两处同名反向出现，“减：超限额应扣除的部分”四行同名，诊断记“歧义待确认/口径冲突”，
  保留得分最高记录（2024：-35,293.85 / -38,099.82）。
- 定位诊断里 MINIMUM_CAPITAL 的页码仍显示 33/20/21/16，但表对象与标准化数值已由 extractor 纠正到
  40/39/39/37；若共享层修复第 5 节缺陷 1，可去掉 extractor 里的页码改写。
- 2022 无近三年（综合）投资收益率表，`THREE_YEAR_INVESTMENT_RETURN` 定位为空是正确的缺失表达。
